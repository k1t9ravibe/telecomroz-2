# Мониторинг стоимости аренды — АО «Казахтелеком»

Информационная система для анализа стоимости аренды помещений при закупках способом из одного источника:
единая база цен за 1 м² по регионам Казахстана, автоматическое выявление превышения ценовых ориентиров,
анализ рыночных предложений и формирование справок.

## Запуск

```bash
cd rent-monitoring
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (статические файлы, можно разместить на любом веб-сервере)
npm test           # модульные тесты расчётов и импорта Excel
```

## Хранение данных

* **По умолчанию** — локальная база браузера (localStorage): данные не исчезают после обновления страницы.
  При первом запуске загружается демонстрационный набор (все записи помечены «демо»).
* **Supabase / PostgreSQL** — выполните `supabase/schema.sql` в SQL Editor проекта Supabase и создайте `.env`
  по образцу `.env.example` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`). Пустая база заполняется демо-данными
  автоматически. Политики RLS в схеме открыты для демонстрации — для эксплуатации замените их на ролевые.

## Логика расчётов

* Цена за 1 м² = ежемесячная стоимость аренды / площадь.
* Ценовой ориентир — **медиана** сопоставимых фактических ставок из базы цен за последние 12 месяцев
  (период и минимальное число объектов настраиваются). Сопоставимость: населённый пункт + тип + диапазон площади;
  при недостатке данных выборка расширяется (населённый пункт + тип → регион + тип + площадь → регион + тип).
  Если объектов меньше минимума — «Недостаточно данных для формирования ценового ориентира».
* Отклонение = (цена − ориентир) / ориентир × 100%. Превышение подсвечивается, но **не блокирует** заявку.
* Согласованные заявки автоматически добавляются в базу цен как завершённые закупки.
* Рыночные предложения (Krisha.kz и др.) — только дополнительный ориентир; интеграция с Krisha.kz
  планируется через официальный API, сейчас — ручной ввод и загрузка Excel.

## Структура

```
src/lib/stats.ts      расчёт цены за 1 м², медианы, ориентира, отклонения
src/lib/storage.ts    хранилище: localStorage или Supabase
src/lib/seed.ts       демонстрационные данные
src/lib/excel.ts      импорт/экспорт Excel, шаблоны
src/lib/pdf.ts        PDF-справка (шрифт Liberation Sans, лицензия OFL — public/fonts)
src/pages/*           страницы: Главная, Заявки, База цен, Рыночный мониторинг, Аналитика, Справки, Настройки
```

Роль пользователя (специалист по закупкам / заказчик) переключается в шапке: специалист запрашивает обоснование
цены, заказчик отвечает пояснением и прикрепляет документы в карточке заявки.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает приложение при каждом push в `main` и публикует его по адресу
`https://<владелец>.github.io/telecomroz-2/rent-monitoring/` (прежнее приложение TelecomRoz — в корне сайта).
Однократно включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
